# Lab 3 – Data Preprocessing and Exploratory Data Analysis

## Aim
To understand and implement data preprocessing techniques using NumPy, Pandas, Matplotlib, Seaborn and Scikit-learn.

## Problem Statement
To analyze a sample student placement dataset and perform data cleaning, missing value handling, label encoding, feature selection and data visualization.

## Experiments Performed

1. NumPy numerical operations.
2. Dataset loading using Pandas.
3. Exploratory Data Analysis (EDA).
4. Data cleaning.
5. Missing value handling.
6. Label Encoding.
7. Feature Selection.
8. Train-Test Split.
9. Data Visualization.

## Libraries Used
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Algorithm
1. Import the required libraries.
2. Load the student placement dataset.
3. Explore the dataset using head(), info() and describe().
4. Identify missing values.
5. Replace missing numerical values with the median.
6. Replace missing categorical values with the mode.
7. Apply Label Encoding to categorical columns.
8. Select important features using SelectKBest.
9. Divide the dataset into training and testing sets.
10. Generate graphs and save the cleaned dataset.

## Results
The dataset was successfully loaded and analyzed. Missing values were handled, categorical data was encoded, important features were selected and the data was divided into training and testing sets.

## Output Files
- placement_distribution.png
- cgpa_distribution.png
- cleaned_dataset.csv

## Performance Analysis
This experiment focuses on data preprocessing rather than training a prediction model. Therefore, classification accuracy, precision, recall and F1-score are not applicable here.

## Learning Outcomes
- Learned NumPy numerical operations.
- Understood Pandas data handling.
- Learned exploratory data analysis.
- Understood missing value treatment.
- Practised label encoding and feature selection.
- Learned data visualization.
- Understood train-test splitting.

## Conclusion
The experiment demonstrated how raw data can be cleaned, transformed and prepared for machine learning applications.
