# Lab 6: PyTorch Basics, Linear Regression and Neural Networks

## Aim
To understand PyTorch tensor operations, automatic differentiation, Linear Regression, and basic Neural Network implementation.

## Problem Statement
Implement basic PyTorch operations, train a Linear Regression model, and build a Neural Network to learn the XOR operation.

## Tools and Libraries
- Python
- PyTorch
- Matplotlib

## Experiments Performed

### 1. Tensor Operations
Performed tensor creation, addition, multiplication, and mean calculation using PyTorch.

### 2. Autograd
Used automatic differentiation to calculate the gradient of a mathematical function.

### 3. Linear Regression
Created and trained a Linear Regression model using a generated dataset and Mean Squared Error loss.

### 4. Neural Network
Created a neural network with an input layer, hidden layer, and output layer to learn the XOR operation.

## Results
- Successfully performed tensor operations.
- Calculated gradients using Autograd.
- Trained a Linear Regression model.
- Implemented a basic Neural Network.
- Generated graphs showing regression and training loss.

- Learned the basics of PyTorch.

- Understood Linear Regression.

The experiment demonstrated the use of PyTorch for tensor operations, automatic differentiation, Linear Regression, and Neural Network training.
