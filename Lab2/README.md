# Lab 2 – Search Algorithms in Artificial Intelligence

## Aim
To understand and implement different search algorithms used in Artificial Intelligence.

## Experiments Performed

1. Breadth First Search (BFS)
2. Depth First Search (DFS)
3. Hill Climbing
4. Best First Search
5. A* Search Algorithm

## 1. Breadth First Search
BFS is an uninformed search algorithm that explores nodes level by level using a queue.

## 2. Depth First Search
DFS is an uninformed search algorithm that explores one branch deeply before backtracking. It uses recursion or a stack.

## 3. Hill Climbing
Hill Climbing is a heuristic search algorithm that selects a better neighbouring state at each step until no improvement is possible.

## 4. Best First Search
Best First Search selects the most promising node based on its heuristic value.

## 5. A* Search
A* is an informed search algorithm that uses actual path cost and estimated remaining cost.
