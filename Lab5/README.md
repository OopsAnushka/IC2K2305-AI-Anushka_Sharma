# Lab 5: Decision Tree Classifier and Model Evaluation

## Aim
To implement a Decision Tree Classifier using Python and evaluate its performance on a student placement dataset.

## Problem Statement
Predict whether a student will get placed based on CGPA, internships, gender, and course.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Joblib

## Algorithm
1. Load the student placement dataset.
2. Handle missing values.
3. Separate input features and target variable.
4. Convert categorical data into numerical form.
5. Split the dataset into training and testing sets.
6. Create a Decision Tree Classifier.
7. Train the model.
8. Predict student placement.
9. Evaluate the model using accuracy, confusion matrix, precision, recall, and F1-score.
10. Visualize and save the decision tree.
11. Save the trained model.

## Results
The Decision Tree Classifier was successfully implemented to predict student placement.

The model was evaluated using:
- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-score

## Output Files
- `confusion_matrix.png`
- `decision_tree.png`
- `classification_report.txt`
- `decision_tree_output.png`

## Learning Outcomes
- Understood supervised machine learning.
- Learned how a Decision Tree works.
- Practiced model training and prediction.
- Learned model evaluation techniques.
- Visualized a trained decision tree.

## Conclusion
The experiment demonstrated how a Decision Tree Classifier can be used for student placement prediction and how machine learning models are evaluated using performance metrics.
