# Lab 4 – Knowledge Representation and Logical Reasoning

## Aim
To understand and implement different knowledge representation techniques used in Artificial Intelligence.

## Problem Statement
To represent knowledge using predicates, semantic networks, frames, conceptual dependency and rule-based systems, and demonstrate logical inference.

## Concepts Implemented

1. Knowledge Representation
2. Predicate Representation
3. Logical Inference
4. Semantic Networks
5. Frame Representation
6. Conceptual Dependency
7. Rule-Based Systems

## Algorithm

1. Define facts using predicate representation.
2. Store relationships between objects.
3. Apply logical rules to derive new facts.
4. Construct a semantic network using nodes and relationships.
5. Represent an object using frames and slots.
6. Represent an action using conceptual dependency.
7. Apply IF-THEN rules to make decisions.
8. Display the results.

## Results

The program successfully represented facts, generated inferred knowledge, constructed a semantic network, created a frame and demonstrated rule-based decision-making.

## Applications
- Expert systems
- Medical knowledge representation
- Intelligent chatbots
- University knowledge bases
- Recommendation systems

## Learning Outcomes

- Understood knowledge representation in AI.
- Learned predicate representation.
- Understood semantic networks and frames.
- Learned conceptual dependency.
- Implemented logical inference.
- Understood rule-based reasoning.

## Conclusion

This experiment demonstrated different techniques for representing knowledge and performing logical reasoning in Artificial Intelligence.
